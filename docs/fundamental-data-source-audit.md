# 期货基本面数据源审计

更新日期：2026-07-30

## 结论

工作站的基本面层分为两类：

1. 可统一自动更新的数据：主力期现基差、交易所仓单。
2. 品种专属产业数据：供给、需求、主流企业现金成本、产业库存。

第一类已经扩展到全品种映射。第二类已为当前 63 个品种建立固定来源计划，但多数完整历史序列需要资讯商授权，不能把公开周报摘要拼接成连续数据库。

逐品种来源配置位于 `config/fundamental_sources.json`。网页只把已抓取数值显示为事实；“来源已定位”与“待授权”都不等同于数值已经接入。

## 二级来源

曲合期货、和讯期货、期货日报、金十期货和东方财富资讯适合发现事件、核对发布时间或定位原始数据，不作为连续供需序列的第一来源。快讯只能进入“事件事实”，不能替代产量、消费、成本和库存数值。

豆包搜索与秘塔 AI 当前没有接入本工作区的可调用连接，也未使用登录态代用户检索。对于固定资讯网站仍未定位的数据，本轮使用公开网页搜索补查；后续若接入对应搜索服务，应继续回到原始发布页核验。

## 当前缺失

- 供给、需求、现金成本、产业库存：63 个品种均已定位首选来源，但尚未形成全量自动数值序列。
- 现金成本是最大缺口。多数资讯商只在付费周报或数据库中提供；贵金属还需按主流矿企季度报告统一 AISC/现金成本口径。
- 生意社期现表未覆盖或未能一一对应：氧化铝、花生、豆二、苹果、铝合金、红枣、20号胶、低硫油、双胶纸、粳米。
- 东方财富截至 2026-07-28 的抓取窗口没有仓单记录：燃料油、苹果。这里表示“当期无记录”，不表示仓单为零。
- SMM 数据必须在取得授权后通过许可方式接入，不做网页爬取。

## 日常更新规则

1. 每个交易日更新基差和仓单，并保留来源日期、状态和缺失品种。
2. 周度产业数据只在固定发布日更新，不把上一周数值标成当日事实。
3. 付费来源未授权时，页面展示来源、频率和“待授权”，不填估算值。
4. 资讯快讯只记录事件与发布时间，不从叙述中反推连续数值。
5. 新数据源接入前先固定指标定义、单位、样本范围、频率和历史可得性，再进入图表。
