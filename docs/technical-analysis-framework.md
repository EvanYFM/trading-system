# 技术面分析框架

技术面位于交易系统最后一层，只负责确认入场、止损和退出。它不能替代宏观、基本面和资金判断。

## 三层分析

### 大周期定方向

先判断上涨、下跌还是震荡，再判断处于启动、加速、末端、调整或反转观察阶段。主要工具是前高前低、趋势线、均线和箱体边界。

波浪理论只辅助判断阶段，不用于精确预测。浪 5 伴随量价背离、媒体狂热或拥挤升温时，不追第一买点；结构数不清时，直接归为不确定。

### 中周期定结构

寻找反转形态或持续形态，并标出关键位：

| 类型 | 常见形态 | 成立条件 |
| --- | --- | --- |
| 反转 | 头肩顶底、双顶双底、三重顶底、楔形 | 突破颈线或边界后才成立 |
| 持续 | 旗形、三角旗、平台整理 | 原趋势明确，整理缩量，顺势突破放量 |

潜在形态不等于已确认形态。突破后回抽不破，通常比盘中第一次刺破更可靠；形态拖延过久或突破后迅速回到区间，视为失败警告。

### 小周期定触发

有效触发至少满足价格确认，并尽量得到成交量或持仓量支持：

- 收盘站上或跌破关键位。
- 回抽关键位不破，支撑与阻力完成转换。
- 小周期前高突破、前低跌破或箱体突破。
- K 线行为与方向一致，且没有明显假突破。

只盘中刺破、无量突破、突破后立即回到区间，或者与大周期和资金方向明显冲突，都不算有效触发。

## 入场与退出

入场优先顺序：突破后回抽确认，其次是突破当日小仓试错。潜在形态阶段只观察。

止损放在形态失效处，不放在情绪舒服的位置。常见失效包括颈线重新失守、价格回到旗面或箱体、突破线被收回，以及前一结构高低点被破坏。

止盈可以使用形态量度目标、前高前低等结构目标，或者趋势中的回撤与结构跟踪。趋势未破坏时，不因短期浮盈随意提前退出。

## 技术面七问

1. 大周期方向是什么？
2. 当前处于启动、加速、末端、调整还是反转观察？
3. 中周期是什么形态，关键位在哪里？
4. 形态已经确认，还是仍处于猜测阶段？
5. 成交量和持仓量是否支持？
6. 错了在哪里退出，对了在哪里止盈？
7. 这次触发是否与主要矛盾、资金和交易周期一致？

## 不交易

- 只看小周期图形，宏观、基本面和资金没有方向。
- 形态尚未确认，却提前重仓或买入短期期权等待突破。
- 止损过远，导致仓位无法承受正常波动。
- 风险收益比不足，或者只是因为怕错过而追第一根突破。
- 处于大亏冷却期，却把技术信号当成恢复实盘的理由。

> 大周期定方向，中周期定结构，小周期定触发；形态未确认不重仓，止损不清不交易。
