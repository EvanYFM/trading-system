# 交易日志框架

日志只承担三件事：开仓前固化假设，持仓中检查原逻辑，平仓后区分判断问题与执行问题。不要重复写长篇市场综述。

## 每日观察

每天只记录会影响交易决策的变化：

- 市场主要矛盾是否改变。
- 宏观与流动性环境。
- 板块和重点品种的资金边际变化，注明数据日期。
- 新形成或正在衰减的市场叙事。
- 关键价格结构和次日触发条件。

## 单笔交易卡

### 开仓前

- 日期、品种、合约、方向、工具：
- 交易周期和最长持有时间：
- 主要矛盾：
- 传导链与最关键的验证指标：
- 流动性、资金、叙事、周期的验证结论：
- 资金数据披露日期：
- 最强反方逻辑与 24 小时反向信号：
- 技术触发：
- 逻辑证伪与技术止损：
- 止盈计划：
- 仓位性质、最大可承受亏损与仓位：配置仓 / 交易仓：
- 情绪状态和是否处于冷却期：

### 平仓后

- 实际盈亏和风险收益比：
- 是否按计划入场、止损、止盈和加仓：
- 原假设是正确、错误，还是尚未得到验证：
- 主要错误归因：看对（判断与传导）、做对（时机、工具与执行）、做好（仓位、组合与风险）：
- 下次只改一条什么规则：

## 持仓每日审计

杠杆和期权持仓每天在开盘前、收盘后各填一次。只检查建仓时的原假设，不得用盘中新故事延长持有。

### 建仓后固定，不随亏损改写

- 原始逻辑与预期路径：
- 逻辑兑现的最晚日期，必须早于合约到期日：
- 标的价格或结构的证伪条件：
- 最大可承受亏损、初始仓位和是否允许加仓：

以上四项无法补全，统一标记为：**未完成系统分析。**

### 开盘前：今天还有资格持有吗

- [ ] **空仓测试**：如果现在没有仓位，我还会按当前价格买同一方向、同一工具吗？
- [ ] **原假设**：原始逻辑仍成立吗？我有没有因亏损临时换叙事、改证伪条件或延长等待时间？
- [ ] **反方证据**：隔夜最强反方逻辑和过去 24 小时的反向信号是什么？
- [ ] **价格验证**：标的的大、中、小周期结构是在确认方向，还是持续拒绝我的判断？
- [ ] **期权归因**：浮亏主要来自方向、入场时机、隐波回落、时间价值还是流动性？
- [ ] **时间预算**：距逻辑兑现期限还有几天？剩余期限是否仍适合表达这条逻辑？
- [ ] **风险状态**：剩余权利金若全部亏完是否仍能承受？当前仓位是否超过原计划？
- [ ] **今日计划**：继续持有、减仓或退出分别由什么客观条件触发？

### 收盘后：市场今天证明了什么

- [ ] 标的今天新增了哪些支持证据和反方证据？哪一边更强？
- [ ] 今日盈亏分别有多少来自标的方向、隐波、时间价值和买卖价差？
- [ ] 我是否按计划执行，有没有补亏损仓、移动止损、频繁盯盘或临时寻找利好？
- [ ] 如果明天重新空仓，我还会建立同一持仓吗？如果不会，继续持有的理由是什么？
- [ ] 明日只保留一个动作计划：触发条件、行动、失效条件。

### 认知偏差自查

勾中任意两项，当天不加仓、不扩大风险；命中一票否决项，按原计划减仓或退出，不再为持仓寻找新理由。

- [ ] **沉没成本与损失厌恶**：因为已经亏了很多，只想等回本再走。
- [ ] **确认偏误与叙事偏误**：只找支持信息，把模糊故事当作可验证事件。
- [ ] **锚定与禀赋效应**：盯着买入价、盈亏平衡价，或因为已经持有而提高主观评价。
- [ ] **行动偏误与 FOMO**：焦虑时频繁操作，害怕卖出后马上反向。
- [ ] **赌徒谬误与结果偏误**：认为连跌后必然反弹，或只用当天盈亏评价决策质量。
- [ ] **目标漂移**：证伪后改逻辑、下移止损、延长周期或把短线改成长线。

一票否决：只为回本而持有；原逻辑已失效；逻辑兑现期限已过；空仓测试不通过却不愿退出；计划外补亏损仓；因亏损扩大风险。

## 复盘原则

- 盈利不自动证明判断正确，亏损也不自动证明判断错误。先看过程是否符合系统。
- 把行情判断错和执行纪律错分开。前者改研究，后者改规则或降低交易权限。
- 复盘只沉淀可执行规则，不写“下次更谨慎”一类空泛结论。
- 同类错误重复两次，就要进入清单、仓位限制或冷却规则。
- 每周只统计少量指标：系统内交易占比、纪律违规次数、平均盈亏比、最大回撤和主要错误类型。
