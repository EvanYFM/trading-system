# 交易哲学

这份文档只保留长期不轻易改变的原则。具体分析、开平仓和复盘分别见 `docs/trading-system.md`、`docs/trading-decision-checklist.md` 和 `docs/trading-log-framework.md`。

## 市场与认知

- 市场是客观的，交易者会犯错。亏损先检查判断和执行，不与市场争辩。
- 交易是概率游戏。优势只代表长期胜率和赔率，不保证单笔正确。
- 事实约束长期，共识影响中短期定价，价格验证共识是否变化。逆共识交易必须等价格或资金先给证据。
- 市场会在不同时期交易不同的主要矛盾。框架用于寻找主导逻辑，不能机械打分。
- 价格常沿最小阻力线运行。震荡时少预测，趋势形成后再跟随。

## 模型与方法

- 投资很难像实验室科学那样隔离变量并稳定重复，但应保持科学态度：尊重证据、提出可证伪的假设、记录结果并持续修正。
- 理论、模型和指标都是对市场的简化，只在特定制度、周期和参与者结构下有用。它们帮助组织信息，不能消除随机性，也不能代替判断。
- 历史数据可以淘汰表现差的假设，却很难证明某条规律永远有效。回测结果必须接受样本外行情和真实交易的检验。
- 好的交易假设必须允许自己被证明是错的。反向证据出现时更新判断，不能不断增加解释来保护原有观点。
- 交易系统不能照搬他人的智慧。框架可以借鉴，结论要经过自己的知识、经历和交易日志校准。系统永远保持开放，但只在复盘后修改，不在持仓压力下改写。

## 能力圈与机会

- 看不懂的不做。股票要看懂价值和安全边际，期货与期权要看懂产业矛盾、期限结构和风险收益比。
- 价格低不等于便宜，价格高也不等于马上反转。先区分价值错配、周期错配和基本面塌陷。
- 拥挤和舆论热度是风险提示，不是独立的反向信号。狂热时防接盘，恐慌时也要等待基本面与价格确认。
- 股票和基金可以用时间换空间；杠杆品种更依赖右侧确认、明确止损和小仓试错。

## 风险与仓位

- 本金安全高于收益速度。只承担开仓前已经接受的亏损。
- 杠杆会放大错误。判断不清、波动过大或周期混乱时，先降仓或不交易。
- 初始仓位用于试探。市场证明方向后才能考虑加仓，亏损仓不补，止损不下移。
- 止损代表交易假设失效，不代表能力被否定。活着等下一次机会比证明这一次正确更重要。
- 大赚后出金或降低风险，大亏后休息。冷却期的任务是恢复判断力，不是追回亏损。

## 情绪与执行

- 怕错、怕亏、怕错过和怕赚不到，都会让判断偏离系统。情绪明显激动或急于回本时不下单。
- 每笔交易相互独立。连续盈利不自动放大仓位，连续亏损不降低下一笔的入场标准。
- 持仓后持续寻找反方证据。不能因为已经持仓，就临时更换逻辑或忽略反向信号。
- 少交易。利润来自少数证据充分、赔率合适的机会，不来自每天都要参与。

## 一句话原则

> 先保护本金，在能力圈内寻找主要矛盾和最小阻力线；用小仓位验证判断，用价格确认方向，用纪律处理错误。
