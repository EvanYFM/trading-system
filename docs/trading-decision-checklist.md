# 交易决策检查清单

每笔交易在下单前完成。任何关键项答不清，结论都是：**未完成系统分析，不建议直接执行。**

## 开仓前十问

- [ ] **主要矛盾**：市场当前真正交易什么？传导链和最关键的验证指标是什么？我的方向和交易周期是什么？
- [ ] **四项验证**：流动性、资金仓位、叙事共识和周期位置是否支持？资金数据披露日期是什么？
- [ ] **能力圈**：我真的看得懂吗？风险收益比或安全边际够吗？
- [ ] **空仓测试**：如果现在是空仓，我仍愿意在这个价格按同方向开仓吗？
- [ ] **反方测试**：最强反方逻辑是什么？过去 24 小时出现过哪些反向信号？
- [ ] **技术触发**：突破、回踩、结构转折或第二类买卖点已经确认了吗？若做空头趋势中的左侧反转，是否至少出现利空不跌、趋势转盘整，并有拥挤度或资金转向验证？
- [ ] **风险计划**：逻辑证伪、技术止损、止盈位置和最长持有时间写清了吗？
- [ ] **仓位工具**：这是配置仓还是交易仓？最大能亏多少钱？仓位和期货、期权、股票是否匹配这个周期？
- [ ] **情绪拥挤**：紧急感、趋势破圈、身边共识和持有人扩散是否有两项以上过热？我是在执行计划，还是因为 FOMO 或急于回本而下单？
- [ ] **纪律状态**：我是否处于大亏、连续亏损或冷却期？这笔交易是否违反暂停规则？

## 一票否决

- 看不懂，或主要矛盾说不清。
- 没有技术触发、证伪条件或止损止盈。
- 因为别人赚钱、热门叙事或害怕错过而追单。
- 开盘前半小时临时起意追单，且开盘前没有明确预案。
- 判断不清却使用杠杆，或者仓位无法承受正常波动。
- 单月大亏、连续 3 笔亏损或急于回本后，尚未完成冷却复盘。
- 计划亏损补仓、下移止损或用新理由掩盖原逻辑失效。

## 持仓与复盘

- 每日持仓按 `docs/trading-log-framework.md` 的“持仓每日审计”在开盘前、收盘后各检查一次。
- [ ] 入场后出现了支持证据，还是只剩主观期待？
- [ ] 止损、止盈和加仓是否按计划执行？
- [ ] 有没有因持仓寻找支持自己的证据，忽略反向变化？
- [ ] 期权盈亏来自方向、时机、隐波、时间价值还是流动性？
- [ ] 结果应归因于判断、仓位、工具、执行还是情绪？
